# Nextaction pilot — whale-накопичення → прогноз ціни (підсумок)

Пілот 2026-07-18/19. Мета: чи можна прогнозувати рух ціни активу за емісією набраного/проданого
китами (~500 гаманців, за якими стежить Wallet Radar). Крейт `/opt/wallet-tracker/nextaction/`.

## Ланцюг A→D

- **A — netflow** (`src/netflow.rs`): whale accumulation/distribution по (chain,token) з
  backfill transfers.csv. Спам-фільтр `distributors==0` відсіяв 14131 з 20895 токенів. 678 реальних.
- **B — step-b-prices.sh + backfill**: повна ERC-20 історія 500 китів (backfill, ~1.25 ГБ,
  3.6М whale-рядків, complete 2026-07-19) + денні ціни DefiLlama (chart span=500) для ~618 токенів.
- **C — signal** (`src/signal.rs`): IC + event-study + null-baseline, 3 варіанти сигналу.
- **D — backtest** (`src/backtest.rs`): walk-forward (no lookahead), raw + market-neutral + long-short sweep.

## ГОЛОВНИЙ ВИСНОВОК

**Наші кити — КОНТРАРІАННИЙ індикатор.** Сильне доларове НАКОПИЧЕННЯ токена нашими китами
передує ПАДІННЮ його ціни (а не росту, як наївно очікувалось). Знак сигналу ІНВЕРТОВАНИЙ.

**Кількісно (market-neutral, walk-forward, no lookahead):**
- SHORT на топ-10% USD-накопичення: чистий edge над ринком **+3.1 / +4.2 / +5.3%** на 7/14/30д,
  hit-rate **62-64%** (частка сигналів, де токен недоперформив ринок).
- event-study надлишок (vs per-token база): −3.2 / −5.6 / −7.4% на 7/14/30д, null≈0.

## Що перевірено (сигнал СТІЙКИЙ)

1. **Null-значущість:** реальний надлишок vs перемішані мітки ≈0 → не випадковість (28-45% токенів значущо).
2. **Робастність до вибірки:** стабільно на 54%→78%→100% backfill.
3. **Робастність до вікна W:** тримається на W=1/7/14 (найсильніше 7-14д).
4. **USD > обсяг > breadth:** драйвер — ДОЛАРОВИЙ обсяг накопичення, не кількість китів
   (breadth найслабший). «Гроші, а не натовп.»
5. **Market-neutral:** edge зберігається після віднімання ринку режиму (+3-5%).
6. **Decile:** оптимум top-10% (top-5% не сильніший — ефект не суто в хвості).

## Що НЕ працює (важливі негативи)

- **LONG-нога:** сильне РОЗПОДІЛ китами (bottom-децил) НЕ передує росту — токен теж падає.
  Симетричної long-short стратегії НЕМАЄ. Екстремальна whale-активність у БУДЬ-ЯКИЙ бік → underperformance.
- Тредебл лише **SHORT / AVOID** на накопиченні.

## Обмеження

- Період вибірки **ведмежий** (базовий return усіх токенів від'ємний) — market-neutral це прибирає,
  але режимна залежність можлива.
- Ціни DefiLlama, ~618 токенів (134 без ціни); дрібні/неліквідні пропущені.
- Backfill = 500 китів (не 25k). Amount у token-одиницях, decimals-нормалізовано, не supply-нормалізовано.
- Edge помірний (+3-5% market-neutral) — робочий, але не «золота жила»; після комісій/прослизання менший.

## Рекомендація для прода

Інтегрувати як сигнал **AVOID/SELL**, не BUY: коли наші кити сильно (топ-10% USD за 7-14д)
заливають гроші в токен — це попередження про ймовірне падіння (−3-5% відносно ринку, 62-64% влучань).
Показувати у картці активу як «⚠️ кити активно набирають — історично контраріан».
Наступні кроки для продакшн-моделі: supply-нормалізація, розширення до 25k гаманців,
контроль ринкового beta, out-of-sample на бичачому періоді.
